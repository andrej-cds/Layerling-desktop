## What's new in 1.109.9

Only the desktop part changes in this release (layerling stays at 1.109.0).

- **Open in Fusion: no more Fusion crashes after the import**
  The model is imported into the empty "Untitled" document that Fusion opens at start, and that document is no longer closed (closing it while Fusion was loading sometimes crashed Fusion). The file name is set a few seconds later.

---

## Kaj je novega v 1.109.9

V tej izdaji se spremeni samo namizni del (layerling ostaja pri 1.109.0).

- **Odpiranje v Fusionu: Fusion se po uvozu ne sesuje več**
  Model se uvozi v prazen »Untitled«, ki ga Fusion odpre ob zagonu, ta dokument pa se ne zapira več (zapiranje med nalaganjem je Fusion včasih sesulo). Ime datoteke se nastavi nekaj sekund pozneje.
