## What's new in 1.107.4

Only the desktop part changes in this release (layerling stays at 1.107.0).

- **STEP with a special character in its name opens in Fusion**
  Fusion's launcher gets the file name as plain ANSI text, so a name with a letter such as č could not be found and the model did not open (a file without such letters did). The program now opens a copy with a plain name (č becomes c) from the temporary folder. The original stays where you saved it.
- **A cold start of Fusion waits long enough**
  After starting Fusion the program now waits at least half a minute and until the window shows a document before it sends the file.

## Kaj je novega v 1.107.4

V tej izdaji se spremeni samo namizni del (layerling ostaja pri 1.107.0).

- **STEP s posebnim znakom v imenu se odpre v Fusionu**
  Fusionov zaganjalnik dobi ime datoteke kot navadno besedilo ANSI, zato imena s črko, kot je č, ni našel in model se ni odprl (datoteka brez takih črk je delovala). Program zdaj odpre kopijo z navadnim imenom (č postane c) iz začasne mape. Original ostane tam, kamor si ga shranil.
- **Hladen zagon Fusiona počaka dovolj dolgo**
  Po zagonu Fusiona program zdaj počaka vsaj pol minute in da okno pokaže dokument, preden pošlje datoteko.
