## What's new in 1.92.2

- **An OBJ from Tinkercad comes in the right way up**
  Tinkercad writes its OBJ files with Z up. layerling used to read them with Y up, so a part stood on its edge. layerling now recognises a Tinkercad file and sets it down the right way: a flat part lies flat.
- **A .lyl file opens with a double click**
  When layerling is installed as an app (Chrome or Edge), it registers itself with the system as a program for .lyl files. A double click on a design in the file manager opens it in layerling right away, and Ctrl+S saves back into that file. The system asks once which program to use.
- **Docker: the preview pictures appear**
  In the ready-made Docker image the cards on the start page stayed on "No preview yet", because the server was not allowed to create a folder for the pictures. The folder now belongs to the server's user, so the pictures are saved again. For an existing container, pull the image again; the pictures appear the next time a design is opened.
- **Docker behind a proxy: saving to the server works**
  If you run layerling behind a reverse proxy with a domain and HTTPS, saving to the server failed with "Shared projects only accept requests from this site". layerling now copes with a proxy that ends HTTPS without passing that on. If the proxy changes the host, list the domain in LAYERLING_ALLOWED_ORIGINS.
- **Delete all reference points in the menu of an empty spot too**
  If you had set a reference point with the tape measure and right-clicked next to it, you found only Paste, Select all and Select multiple. "Delete all reference points" is now in the menu of an empty spot of the 3D view too, whenever the design holds a reference point.
- **The number field of the corner ruler closes on deselect**
  A click on a green number of the corner ruler opens a field to type into. It stayed in the view even when the body was no longer selected. It now closes (without applying) as soon as the bodies it was opened for are no longer all selected.

## Kaj je novega v 1.92.2

- **OBJ iz Tinkercada pride pravilno obrnjen**
  Tinkercad zapiše datoteke OBJ z osjo Z navzgor. Layerling jih je prej bral z osjo Y navzgor, zato je del stal na robu. Layerling zdaj prepozna datoteko iz Tinkercada in jo postavi pravilno: ploščat del leži ploščato.
- **Datoteka .lyl se odpre z dvojnim klikom**
  Ko je Layerling nameščen kot aplikacija (Chrome ali Edge), se pri sistemu prijavi kot program za datoteke .lyl. Dvojni klik na osnutek v upravitelju datotek ga takoj odpre v Layerlingu, Ctrl+S pa shrani nazaj v to datoteko. Sistem enkrat vpraša, kateri program uporabiti.
- **Docker: predogledne slike se pojavijo**
  V že pripravljeni sliki Docker so kartice na začetni strani ostale pri »Še ni predogleda«, ker strežnik ni smel ustvariti mape za slike. Mapa zdaj pripada uporabniku strežnika, zato se slike spet shranjujejo. Pri obstoječem vsebniku sliko znova povleci; slike se pojavijo, ko osnutek naslednjič odpreš.
- **Docker za posredniškim strežnikom: shranjevanje na strežnik deluje**
  Če poganjaš Layerling za obratnim posredniškim strežnikom z domeno in HTTPS, shranjevanje na strežnik ni uspelo z »Skupni projekti sprejemajo zahteve samo s tega mesta«. Layerling se zdaj spopade s posrednikom, ki konča HTTPS, a tega ne posreduje naprej. Če posrednik spremeni gostitelja, domeno navedi v LAYERLING_ALLOWED_ORIGINS.
- **Izbriši vse referenčne točke tudi v meniju praznega mesta**
  Če si z merilnim trakom nastavil referenčno točko in desno kliknil ob njej, si našel samo Prilepi, Izberi vse in Izberi več. »Izbriši vse referenčne točke« je zdaj tudi v meniju praznega mesta 3D pogleda, kadar osnutek vsebuje referenčno točko.
- **Številčno polje kotnega ravnila se ob odznačitvi zapre**
  Klik na zeleno številko kotnega ravnila odpre polje za vnos. Ostalo je v pogledu, tudi ko telo ni bilo več izbrano. Zdaj se zapre (brez uveljavitve), čim telesa, za katera je bilo odprto, niso več vsa izbrana.
