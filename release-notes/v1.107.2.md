## What's new in 1.107.2

Only the desktop part changes in this release (layerling stays at 1.107.0).

- **STEP opens in Fusion straight after export**
  Starting Fusion360.exe with the file only started Fusion; the model did not open. The program now uses Fusion's own launcher (FusionLauncher.exe), which opens the file in the Fusion that is already running. It is found by itself, so Fusion updates do not break it. A program chosen by hand in the menu still comes first.

---

## Kaj je novega v 1.107.2

V tej izdaji se spremeni samo namizni del (layerling ostaja pri 1.107.0).

- **STEP se po izvozu takoj odpre v Fusionu**
  Zagon Fusion360.exe z datoteko je Fusion samo zagnal, model pa se ni odprl. Program zdaj uporabi Fusionov zaganjalnik (FusionLauncher.exe), ki datoteko odpre v že zagnanem Fusionu. Najde ga sam, zato ga posodobitve Fusiona ne zlomijo. Program, ki ga izbereš ročno v meniju, ima še vedno prednost.
