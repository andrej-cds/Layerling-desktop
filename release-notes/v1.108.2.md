## What's new in 1.108.2

Only the desktop part changes in this release (layerling stays at 1.108.0).

- **No more black window after it was hidden**
  When the window had been behind other windows (or you work through remote access, e.g. Splashtop), it could come back black, with only the title field drawn. Windows' guess about which windows are covered is switched off, so the window keeps drawing. If it still happens, tell me when it appeared.

---

## Kaj je novega v 1.108.2

V tej izdaji se spremeni samo namizni del (layerling ostaja pri 1.108.0).

- **Okno po skritju ni več črno**
  Če je bilo okno za drugimi okni (ali delaš prek oddaljenega dostopa, npr. Splashtop), se je lahko vrnilo črno, narisano je bilo samo polje z naslovom. Windowsovo ugibanje, katera okna so zakrita, je izklopljeno, zato se okno riše naprej. Če se še zgodi, mi povej, kdaj se je pojavilo.
