## What's new in 1.109.3

Only the desktop part changes in this release (layerling stays at 1.109.0).

- **Open in Fusion: the document gets the file name**
  Fusion names a document imported by a script "Untitled", so the name of the file is now set after the import (for example "Gumb za ključavnico").

---

## Kaj je novega v 1.109.3

V tej izdaji se spremeni samo namizni del (layerling ostaja pri 1.109.0).

- **Odpiranje v Fusionu: dokument dobi ime datoteke**
  Fusion dokument, uvožen prek skripte, imenuje »Untitled«, zato se po uvozu ime datoteke nastavi samo (npr. »Gumb za ključavnico«).
