## What's new in 1.111.5

- **BambuStudio button in the export window (desktop)**
  Next to Fusion and SolidCraft in the Program row there is now a BambuStudio button. It exports OBJ and opens the file in Bambu Studio. The program is found automatically; you can choose it yourself in the desktop settings.

---

## Kaj je novega v 1.111.5

- **Gumb BambuStudio v oknu za izvoz (namizna različica)**
  Poleg Fusiona in SolidCrafta je v vrstici Program zdaj tudi gumb BambuStudio. Izvozi OBJ in datoteko odpre v programu Bambu Studio. Program se najde sam, v nastavitvah namizne različice pa ga lahko izberete tudi ročno.
