## What's new in 1.106.1

- **A safer store folder on your own server**
  If you run layerling on your own web server with a "store" folder: store.php now only accepts export files that really are what their name says, and the folder is no longer served directly. Replace store.php with the new one. Nothing changes on layerling.com or in the Docker image.

---

## Kaj je novega v 1.106.1

- **Varnejša mapa store na tvojem strežniku**
  Če layerling poganjaš na lastnem spletnem strežniku z mapo »store«: store.php zdaj sprejme samo izvožene datoteke, ki so res to, kar pravi njihovo ime, mapa pa se ne streže več neposredno. Zamenjaj store.php z novim. Na layerling.com in v sliki Docker se nič ne spremeni.
