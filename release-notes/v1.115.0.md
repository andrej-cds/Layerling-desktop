## What's new in 1.115.0

- **STEP files with several solids**
  A STEP file from another CAD program, an assembly of posts, rails and panels for example, now comes in as one body each, under the name from the file and in the right place to the others, all selected together. layerling does not take over the colours and groups of the file yet.
- **A clearer start page**
  The designs sit under one heading with Server and Browser tabs, both with the same buttons: New folder, Select, Back up all and Restore backup. On the server too, Back up all now saves everything in one ZIP file. The welcome guide comes first and can be closed, and the notice that designs kept only in the browser can be lost is a clear card.

## Kaj je novega v 1.115.0

- **STEP datoteke z več telesi**
  STEP datoteka iz drugega CAD programa, na primer sestav iz stebrov, letev in plošč, se zdaj naloži kot po eno telo, z imenom iz datoteke in na pravem mestu glede na ostala, vsa skupaj izbrana. Barv in skupin iz datoteke Layerling še ne prevzame.
- **Urejena začetna stran**
  Projekti so pod enim naslovom z zavihkoma Strežnik in Brskalnik, oba z enakimi gumbi: Nova mapa, Izberi, Varnostna kopija vsega in Obnovi kopijo. Tudi na strežniku »Varnostna kopija vsega« zdaj shrani vse v eno datoteko ZIP. Uvodna navodila so zgoraj in jih lahko zapreš, opozorilo, da se projekti, shranjeni samo v brskalniku, lahko izgubijo, pa je opazna kartica.
