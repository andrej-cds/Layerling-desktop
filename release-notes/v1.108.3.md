## What's new in 1.108.3

Only the desktop part changes in this release (layerling stays at 1.108.0).

- **Open in Fusion: no more flicker and no jump to the Home screen**
  When Fusion starts with its empty "Untitled" document, the STEP file is now imported into that document instead of opening a second one. If a design is already open, the file still opens in a new document.

---

## Kaj je novega v 1.108.3

V tej izdaji se spremeni samo namizni del (layerling ostaja pri 1.108.0).

- **Odpiranje v Fusionu: brez utripanja in brez skoka na domači zaslon**
  Ko se Fusion zažene s praznim dokumentom »Untitled«, se datoteka STEP uvozi vanj, namesto da se odpre drugi dokument. Če je dokument že odprt, se datoteka še vedno odpre v novem dokumentu.
