## What's new in 1.109.2

Only the desktop part changes in this release (layerling stays at 1.109.0).

- **Open in Fusion: the tab carries the file name**
  The model is opened as a new document named after the file, like when you open a file by hand in Fusion. The empty "Untitled" that Fusion opens at start is closed only after the import.

---

## Kaj je novega v 1.109.2

V tej izdaji se spremeni samo namizni del (layerling ostaja pri 1.109.0).

- **Odpiranje v Fusionu: zavihek nosi ime datoteke**
  Model se odpre kot nov dokument z imenom datoteke, kot pri ročnem odpiranju v Fusionu. Prazni »Untitled«, ki ga Fusion odpre ob zagonu, se zapre šele po uvozu.
