## What's new in 1.111.1

- **Button names in the toolbar**
  Workspace settings has a new choice, Button names: icons only (as before), icons with the name under each one, or names only. It works in the desktop and the web version and is remembered.
- **SolidCraft button in the export window (desktop)**
  Next to Fusion in the Program row there is now a SolidCraft button. It exports STEP and opens the file in SolidCraft. Choose the SolidCraft program once in the desktop settings.

---

## Kaj je novega v 1.111.1

- **Imena gumbov v orodni vrstici**
  Nastavitve delovnega prostora imajo novo izbiro Imena gumbov: samo ikone (kot doslej), ikone z imenom pod vsako ali samo imena. Deluje v namizni in spletni različici, izbira se zapomni.
- **Gumb SolidCraft v oknu za izvoz (namizna različica)**
  Poleg Fusiona je v vrstici Program zdaj tudi gumb SolidCraft. Izvozi STEP in datoteko odpre v programu SolidCraft. Program SolidCraft enkrat izberete v nastavitvah namizne različice.
