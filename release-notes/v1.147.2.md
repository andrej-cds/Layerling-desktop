## What's new in 1.147.2

- **Pictures for server folders**
  Every folder on the server can now have a picture: in the folder's menu (three dots) choose "Add picture", "Change picture" or "Remove picture". The picture is kept in the folder on the server, so it shows in the web version, on the iPad and in the desktop program.
- **Tighter program icon**
  The line under the CDS lettering is as wide as the lettering, so the logo fills the icon more. The web app icons are transparent too.

---

## Kaj je novega v 1.147.2

- **Slike za mape na strežniku**
  Vsaka mapa na strežniku lahko zdaj dobi sliko: v meniju mape (tri pike) izberi »Add picture«, »Change picture« ali »Remove picture«. Slika je shranjena v mapi na strežniku, zato se prikaže v spletni različici, na iPadu in v namiznem programu.
- **Ožja črta v ikoni programa**
  Črta pod napisom CDS je zdaj široka kot napis, zato logotip bolj zapolni ikono. Tudi ikone spletne aplikacije so prozorne.
