## What's new in 1.147.4

- **Folder pictures now work in the desktop app**
  "Add picture" in the desktop app ended with an error about a ".lyl package". The desktop app now saves, shows and removes folder pictures just like the web version. Nothing on the server was damaged.

---

## Kaj je novega v 1.147.4

- **Slike map zdaj delujejo tudi v namiznem programu**
  »Add picture« se je v namiznem programu končal z napako o paketu ».lyl«. Namizni program zdaj slike map shrani, prikaže in odstrani enako kot spletna različica. Na strežniku se ni nič poškodovalo.
