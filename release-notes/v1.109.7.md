## What's new in 1.109.7

Only the desktop part changes in this release (layerling stays at 1.109.0).

- **Open in Fusion: Fusion no longer crashes after the import**
  Naming the document with the file name now happens a few seconds later, when Fusion has finished loading, instead of during the import.

---

## Kaj je novega v 1.109.7

V tej izdaji se spremeni samo namizni del (layerling ostaja pri 1.109.0).

- **Odpiranje v Fusionu: Fusion se po uvozu ne sesuje več**
  Poimenovanje dokumenta z imenom datoteke se zdaj zgodi nekaj sekund pozneje, ko se je Fusion že naložil, in ne med uvozom.
