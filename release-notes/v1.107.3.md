## What's new in 1.107.3

Only the desktop part changes in this release (layerling stays at 1.107.0).

- **STEP opens in Fusion even when Fusion was closed**
  When Fusion was not running, it started with an empty document and the exported file was lost. The program now starts Fusion first, waits until it is ready, and only then sends the file. If Fusion is already running, the file opens at once. What it does is written to the log (Fusion: starting / opening).

---

## Kaj je novega v 1.107.3

V tej izdaji se spremeni samo namizni del (layerling ostaja pri 1.107.0).

- **STEP se odpre v Fusionu tudi, ko je bil Fusion zaprt**
  Če Fusion ni tekel, se je zagnal s praznim dokumentom, izvožena datoteka pa se je izgubila. Program zdaj najprej zažene Fusion, počaka, da je pripravljen, in šele nato pošlje datoteko. Če Fusion že teče, se datoteka odpre takoj. Kaj počne, se zapiše v dnevnik (Fusion: zaganjam / odpiram).
