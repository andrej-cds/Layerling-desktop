## What's new in 1.108.1

Only the desktop part changes in this release (layerling stays at 1.108.0).

- **STEP opens in Fusion straight after export, reliably**
  Starting Fusion with the file on the command line turned out to be unreliable: Fusion started, but the model often did not open. The program now hands the file to Fusion through Fusion's own local MCP server (port 27182, switched on in Fusion's settings), which opens the model as a new document. If Fusion is closed, it is started first and the file follows as soon as Fusion answers. Without the MCP server the program falls back to the Fusion launcher, as before.

## Kaj je novega v 1.108.1

V tej izdaji se spremeni samo namizni del (layerling ostaja pri 1.108.0).

- **STEP se po izvozu zanesljivo odpre v Fusionu**
  Zagon Fusiona z datoteko v ukazni vrstici se je izkazal za nezanesljivega: Fusion se je zagnal, model pa se pogosto ni odprl. Program zdaj datoteko preda Fusionu prek njegovega lokalnega strežnika MCP (vrata 27182, vklopi se v nastavitvah Fusiona), ki model odpre kot nov dokument. Če je Fusion zaprt, se najprej zažene, datoteka pa sledi takoj, ko Fusion odgovori. Brez strežnika MCP program kot doslej uporabi zaganjalnik Fusiona.
